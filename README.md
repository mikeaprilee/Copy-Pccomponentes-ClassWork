# 🛒 PcComponentes · Trabajo de clase
Proyecto web realizado para practicar **HTML y CSS** mediante la recreación visual de una tienda de tecnología inspirada en PcComponentes. El objetivo es aplicar estructura semántica, navegación entre páginas, composición de interfaces y estilos visuales en un proyecto estático.
> **Aviso:** este proyecto es educativo y no oficial. No pertenece a PcComponentes ni reproduce sus servicios reales.
## ✨ Qué incluye
- Página de inicio con banner promocional y tarjetas de ofertas de productos.
- Barra de navegación con logo, categorías, buscador y accesos visuales a cuenta, cesta y búsqueda con IA.
- Páginas informativas sobre el equipo, las tiendas y la presentación del proyecto.
- Sección de tienda y comparativa de productos.
- Formularios de contacto y presupuesto.
- Página de preguntas frecuentes.
- Pie de página con enlaces de ayuda, información, contacto, métodos de pago y redes sociales.
- Recursos multimedia propios del trabajo: imágenes de productos, iconos, un vídeo de presentación y audio.
## 🧰 Tecnologías
- **HTML5** para la estructura y el contenido.
- **CSS3** para el diseño, la navegación visual, las tarjetas, los formularios, las transiciones y la distribución de los elementos.
- Recursos multimedia locales, sin frameworks ni dependencias externas para ejecutar la web.

## ▶️ Cómo verlo
Al ser un proyecto estático, no necesita instalación:
1. Clona o descarga este repositorio.
2. Abre `index.html` en un navegador.
3. También puedes servir la carpeta con cualquier servidor local estático para navegar por las páginas y sus recursos.
La página de entrada redirige automáticamente a `GRUPO 3/Michael/index.html`.
## 🎓 Objetivo académico
Este trabajo sirve para practicar:
- Maquetación de páginas web con HTML.
- Organización de un sitio con varias páginas enlazadas.
- Uso de una hoja de estilos común.
- Diseño de menús, buscadores, tarjetas de producto, tablas y formularios.
- Integración de imágenes, iconos, vídeo y audio.
- Aplicación de efectos visuales como sombras, transiciones y estados `hover`.
